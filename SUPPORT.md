# Support

Start with the [documentation](https://hardmax71.github.io/Integr8sCode/) (sources in `docs/`). It covers architecture, deployment and configuration.

Questions, bugs and feature requests all go to [GitHub Issues](https://github.com/HardMax71/Integr8sCode/issues). Search first, since it may already be reported or answered. Bugs use the Bug Report template with reproduction steps, feature requests use the Feature Request template with the use case, and a question that fits neither can be a blank issue.

For privacy questions, GDPR requests or professional support, email [max.azatian@gmail.com](mailto:max.azatian@gmail.com).

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in every interaction.
